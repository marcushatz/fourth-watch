# Side-by-side test: shots 2, 13 and 26

**The question:** can Cut Paper 2.5D look adult, cinematic and emotionally strong when it's done well?

Version A is drawn in code (`build_side_by_side.py`). Version B comes from ChatGPT, run by Marcus. Both aim at this same brief. No animation, no Higgsfield, no credits, and no text in either version.

## Shared rules

Vertical 9:16. Stacked textured paper with real shadows between layers. Lit-set feeling with haze. Muted adult palette. Gold only where God acts. Adult faces and hands, with no big eyes or dot eyes. Modest Adam and Eve. Not a black silhouette, flat vector art, photorealism or a children's book.

## Composition

| Shot | Feeling | Target |
|---|---|---|
| 2 | Awe | One tiny adult on a dark hill, seen from behind. A huge star field fills the top two thirds. No gold. |
| 13 | Connection, quietly going wrong | Adam and Eve from the chest up, in profile, facing each other. Eve holds out the fruit, and Adam's hand closes on it. A tree limb above and dark leaves below. No gold. |
| 26 | Fear | Close on Adam's bowed head and raised shoulders. His eyes are shut, and dark leaves surround him. One thin line of gold far behind him doesn't touch him. |

## Fairness

- Run each prompt in a fresh chat, and don't attach our frames.
- Run each prompt once. Run it once more only if the result breaks a rule: text, wrong fingers, or a different style.
- Crop every image to 9:16 so both versions match.
- Show the strangers unlabeled images in mixed order.

## Decision rule

- Both strong: Cut Paper stays the lead, and the next step is a short motion test.
- Only ChatGPT strong: the style works and code is the limit, so decide how to make the art.
- Only code strong: the style works and code can carry it.
- Both weak: drop Cut Paper for this film.

## Questions for about five strangers

1. Does this look adult or childish?
2. What emotion do you feel?
3. Would you expect a serious Bible short or a children's video?
4. Which version feels most cinematic?
5. Would you keep watching?
