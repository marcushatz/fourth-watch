# Rhyme payoff (the end answers the opening)

- **Job:** make the last image of a story echo the first, so the ending feels earned.
- **Method:**
  - find the hook's object or shape (Ep 1: two upright posts gripped by his hands, the Gaza gate, 16:3);
  - give the ending the same shape (the two middle pillars, 16:29);
  - frame it with the same size and height in frame, or show its absence.
- **Code:** match the marks' framing (size and the subject's height in frame); `callback: true` on the shot for the linter.
- **Status:** recipe. In the pillars demo the rhyme is in the action (two hands, two posts), not yet in a matched composition with the hook.
