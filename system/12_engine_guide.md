## 1. What the engine is, and the folder map

The film is one web page, `index.html`. `engine/render.js` drives headless Chrome, which draws each frame with `window.renderAt(t)`. three.js draws the sets on SwiftShader (software WebGL, 2 CPUs). People are 2D canvas drawings on billboards; text and cards are canvas 2D. ffmpeg encodes. The sound is a Node script that writes a WAV.

**Every frame is a pure function of `t`.**

| Path (in `ep01-samson/film27/`) | What it is |
|---|---|
| `score.js` | The timeline. **Current = v57, the rendered cut** (S01–S23): `add()` only, with no `L()`, direction fields or verse marks |
| `score_v58.js` | The v58 plan: `L()`, direction fields, `marks`, `OUTRO`. Many of its `v` names are not built (§10) |
| `vo.js` | Word times, generated by `tools/make_vo.py`. Never edit by hand |
| `film.js` | The master renderer: shot lookup, 3D pass, rays, bloom, overlays, header, narration |
| `lintel/` | `lw.js` (`LW`: renderer, sky, terrain, props, billboards), `people.js`/`people2.js` (`PP`, `PP2`), `text.js` (`TX`), `cards.js` (`CARDS`) |
| `fw/core.js` | `FW`: palette, easing, seeded rng, `setCam`, `camLerpK`. The other `fw/*.js` files are **not loaded** |
| `scenes/*.js` | Eight Ep 1 sets: gaza, timnah, sorek, lehi, zorah, prison, dagon, day |
| `song.js` = `song_v57.js` | **The current soundtrack** (fixed Oct 31: `song.js` was a stale copy of v46, kept as `song_v46.js`). It writes `out/soundtrack_v57.wav` (149.92 s = END_T + its 5.6 s outro) and copies it to `out/music.wav` |
| `engine/` | The generic film template (`render.js`, `video/boot.js`, `audio/*`). Edit with care |
| `tools/` | Current: `make_vo.py`, `words_from_voice.py`, `render_part.sh`, `render_one57.sh`, `assemble57b.py`. The rest are older |
| `out/` | Renders and logs (1.9 GB). Never copy |

**Ignore** the backups (`*_v46*`, `*_v57a*`, `*_v57b*`, `*_pre_*`, `*backup*`, `song_v27.js`, `song_hook.js`), the brand pages (`endcard_*`, `logo.*`, `wordmark.js`, `charsheet.*`, `wordsheet.*`) and `hook-style/`, `ws/`, `samson-strength/`.

## 2. How a frame is made

`episode.md` → `make_vo.py` → `vo.js` (`lines[i].words = [{ w, s, e }]`) → `score.js` (`SHOTS`, `VERSES`, `markers`) → `render.js` → `renderAt(t)` (`engine/video/boot.js`) → `film.js` `draw(ctx, t)` → ffmpeg.

`film.js` `draw(ctx, t)`:
1. If `t >= END_T`: draw `CARDS.endCard` and stop.
2. Find the shot with `shotAt(t)`, and reset the camera (fov 38, no offset).
3. Draw the picture:
   - for `scene: 'card'`, `CARDS.background`;
   - otherwise `r = SCENES[scene].frame(t, shot, cam)`. Billboards in `r.bill` face the camera, lean back by half its pitch (unless `r.noLean`) and cast from `r.sun`. Then `LW.render`, `r.rays`, bloom, `r.post`, `r.tags`. Errors draw a placeholder card.
4. `r.flash`, `r.dark`, the night scrim behind the top text (`shot.scrim ?? 0.5`), then the overlays (`card`, `pill`, `chapter`, `intro`, `counter`, `tally`, `stamp`, `bubble(s)`).
5. `TX.header`, the title, the narration, and the cut transitions (`dip`: 0.22 s from black; `flashIn`: 0.2 s cream). `Studio.film` adds grain and a vignette.

| On screen | Comes from |
|---|---|
| Header | `TX.header(..., { series: 'ASK THE TEXT', topic: 'SAMSON' })`, hard-coded at `film.js` line 139 |
| Hook title | `title: true`. The words are hard-coded at line 140 (`*` = gold) |
| Narration (burned-in captions) | `film.js` `narration()`: the VO line word by word at y 318 (500 under a title); gold words from `KEYS` (lines 13–17, by VO line). Hidden for `text: false` and under a verse card |
| Mark, end | The header mark is `TX.mark`. `CARDS.endCard` (for `t >= END_T`) never rendered in Ep 1 (`DURATION = END_T`): `assemble57b.py` appended `brand/logo/fw_final_outro_v3.mp4` (0.4–6.0 s), drawn by `endcard_final.*` with `wordmark.js` **(inferred)** |

## 4. The score API

| Call | Returns |
|---|---|
| `cue(line, word, nth = 0)` | A word's start. `line` = 0-based index of the `VO:` lines in `episode.md`, across sections. `word` = text or index; case and punctuation ignored (`'"The'` = `the`); exact match first, then prefix. `nth` = 0-based occurrence. **Throws** if not found |
| `cueEnd(line, word, nth)` / `st(i)` / `ln(i)` / `voEnd` | A word's end, a line's start, a line's object, the end of the last word |
| `PRE = 0.08` | The lead, so a cut lands just before its word: `t0 = cue(...) - PRE` |
| `globalThis.CUE_LOG = []` | Set before loading; it logs `[line, asked, nth, matched, time]` |

`add(id, scene, v, t0, o)` pushes `{ id, scene, v, t0, beats: {}, ...o }`, and `L` is the same function. Each shot ends where the next starts (`t1`, `dur`). `scene` names a `SCENES` module, or `'card'` for 2D only; `v` picks the shot inside that module.

| Render fields (change the picture) | Plan fields (only `tools/shotlist_check.js` reads them) |
|---|---|
| `scene`, `v`, `t0`, `beats` (read by name), `title`, `text: false`, `scrim`, `dip`, `flashIn`, `card` + its fields, `verse`, `verseAt`, `pill`, `pillBeat`, `counter`, `tally`, `stamp`, `bubble(s)` | `size`, `angle`, `act`, `change`, `name`, `cam` (the scene moves the camera), `cuts` (the scene makes them), `long`, `list`, `callback`, `arrival`, `flash` |

**Worked example** (adapted from `score_v58.js`; the verse is shortened here, but a card needs the exact ESV). Line 2 reads "Later, he fell in love with Delilah, and the Philistine lords, … offered her silver …":
```js
L('D1', 'sorek', 'together', st(2) - PRE, { size: 'ms', angle: 'eye', act: 'Samson turns to Delilah', flashIn: true,
  beats: { delilah: cue(2, 'Delilah') } });                          // the scene reads shot.beats.delilah
L('D3', 'sorek', 'silver', cue(2, 'offered') - PRE, { size: 'insert',
  counter: { to: 1100, beat: cue(2, 'silver'), label: 'PIECES OF SILVER', sub: 'FROM EACH LORD · JUDGES 16:5', y: 0.7 } });
const VERSES = [{ text: 'Then Samson called to the LORD and said, ‘O Lord GOD, please remember me …’', ref: 'JUDGES 16:28', maxW: 780,
  marks: [{ phrase: 'please remember me', at: cue(10, 'remember'), kind: 'gold' }] }];
L('M3', 'dagon', 'pray', cue(10, 'he') - PRE, { card: 'verse', verse: 0, verseAt: cue(10, '"O') });
```
- `together` and `silver` were never built, so they render as sorek's default shot.
- A mark's `phrase` must match consecutive verse words (first match wins): `'gold'` for God's act or a key phrase, `'ember'` for the person's choice. The card fades in at `verseAt` and holds to the shot's end.
- `END_T` was `voEnd + 1.3` (v57) and `voEnd + 0.3` (v58). The linter reads `OUTRO` (default 3). Keep `END_T − voEnd` + the outro ≤ 4.5 s (09 §3).
- `markers` (shot ids, plus `{ t, sync }`) give `@name` times to `render.js`.

## 5. Writing a scene module

**The contract** (`scenes/_API.md`): `SCENES.<id> = { async build(env), frame(t, shot, cam) }`, with `env = { W, H, cam }`.
- `frame` returns `{ scene }` plus any grading, `bill`, `sun`, `rays`, `tags` and `post` fields.
- film.js also accepts `rays.screen: [px, py]`, `beforeRender()`, `noLean`, `lift` and `gain`. These are not in `_API.md`.

**Camera:** `FW.setCam(cam, pos, look, fov, roll)`, then `cam.setViewOffset(W, H, dx, dy, W, H)` to shift the frame. `FW.camLerpK(A, B, k)` blends keys `{ p, l, f }`. Focus distance = `-point.applyMatrix4(cam.matrixWorldInverse).z`. `sorek.js` `setCam(k, focusP, ap, sy, roll, sx)` puts the look point at screen fraction (sx, sy). Angles: 06 §7.

**Sets and props:** `LW.sky`, `LW.terrain({ size, seg ≤ 128, hFn, colFn, seed })`, `LW.olive`/`bush`/`rock`/`grassTuft`/`tent`/`banner`/`crate`/`fire` `(rng, scale)`, `LW.particles`, `LW.shaft` (set `uniforms.amt` and `time` every frame), `LW.pool`, `FW.mat`. `prison.js` `Merger()` bakes repeated boxes into one mesh.

**People:**
- Build with `PP2.bill(name, base, over)` or `LW.billboard({ cw, ch, worldH, footPx, draw })`.
- Add the billboard and its `userData.caster` to the scene, and list the visible ones in `bill`.
- Redraw only on a change: `bb.userData.update(JSON.stringify(st), st)`, with quantised values.
- Copy `contactShadow` from `lehi.js` or `sorek.js`.
- **Limits:** cards turn only about the vertical axis, so keep the camera within ±35° of the painted front. `userData.tilt` rolls a card in the picture plane (falls); the back-lean is automatic. Close-ups need a high-resolution crop (`prison.js` `makeSam(crop)`, `PP2.SIZES.samsonCU`).

**Light:**
- A warm `DirectionalLight` key from the upper left (shadows ≤ 2048; 3072 only for a hero set) plus a `HemisphereLight`.
- **Gold, only where the text says God acted:** a `SpotLight('#FFC766')` from the upper left, `LW.shaft`, `LW.pool`, gold motes, the rim (`st.gold`), and `rays: { amt, target }` (wedges from above the top-left corner).
- **Ember:** warm lights on screen right (`sorek.js` `emberSpot`/`emberPt`, `LW.fire`). Keep the light count fixed (`gaza.js` re-places a fixed pool of point lights): new lights recompile shaders.

**Skeleton** (patterns from `prison.js`, `sorek.js`, `lehi.js`):
```js
(function () {
  const S = globalThis.SCORE, FW = globalThis.FW, THREE = globalThis.THREE, LW = globalThis.LW, PP2 = globalThis.PP2;
  const SCENES = (globalThis.SCENES = globalThis.SCENES || {});
  const W = S.W, H = S.H, { clamp, prog, ease } = FW, C = (h) => new THREE.Color(h), q = (v, n = 60) => Math.round(v * n) / n;
  const hFn = (x, z) => (FW.fbm(x * 0.08, z * 0.08, 3, 3) - 0.5) * 0.6;
  let scene, cam, sky, sun, gold, hero;
  function build() {
    scene = new THREE.Scene(); scene.fog = new THREE.Fog(C('#B9B4CC'), 20, 80);
    sky = LW.sky({ top: '#1B2A4E', mid: '#4C5A86', hor: '#E3A98C', low: '#B9B4CC', sunDir: [-0.75, 0.1, -0.66] }); scene.add(sky);
    scene.add(new THREE.HemisphereLight(C('#C4D2EE'), C('#A88B66'), 1.2));
    sun = new THREE.DirectionalLight(C('#FFDDB2'), 3.6); sun.position.set(-12, 8, -6); sun.castShadow = true;  // key, upper left
    sun.shadow.mapSize.set(2048, 2048); scene.add(sun, sun.target);  // also fit sun.shadow.camera to the set (lehi.js)
    gold = new THREE.SpotLight(C('#FFC766'), 0, 30, 0.09, 0.5, 1.2); gold.position.set(-4.6, 12.5, -2.8); scene.add(gold, gold.target);
    scene.add(LW.terrain({ size: 120, seg: 96, hFn, colFn: () => C('#A9B65C') }));
    hero = PP2.bill('person', { v: 2 }, { cw: 1000, ch: 1500, footPx: 60, scale: 2.4 }); scene.add(hero, hero.userData.caster);  // check a still
  }
  const K = (p, l, f = 38) => ({ p, l, f });
  function setCam(k, fp, ap, sy = 0.55) {
    FW.setCam(cam, k.p, k.l, k.f); cam.setViewOffset(W, H, 0, -(sy - 0.5) * H, W, H); cam.updateMatrixWorld();
    return { focus: -new THREE.Vector3(...fp).applyMatrix4(cam.matrixWorldInverse).z, aperture: ap };
  }
  const SH = {};
  SH.plead = (t, shot) => {
    const tR = shot.beats.raise ?? shot.t0 + 0.5, pose = t >= tR - 0.25 ? 'raise' : 'stand';  // anticipation before the word
    hero.position.set(0, hFn(0, 0), 0); hero.userData.update(pose + q(t, 30), { pose, t: q(t, 30) });
    const g = 0; gold.intensity = 14 * g;  // gold only where the text says so
    const u = ease.inOut(clamp((t - shot.t0) / shot.dur));
    const c = setCam(FW.camLerpK(K([0, 1.6, 6], [0, 1.2, 0]), K([0, 1.55, 5.4], [0, 1.2, 0]), u), [0, 1.2, 0], 4.5);
    return Object.assign(c, { bill: [hero], rays: { amt: 0.8 * g, target: [0, 1.4, 0] },
      tags: [{ text: 'NAME', sub: 'BOOK 1:1', p: [0, 2.0, 0], k: prog(t, tR, tR + 0.6, (x) => x), dy: -60, dx: 200 }] });
  };
  SCENES.myset = {
    async build(env) { cam = env.cam; build(); },
    frame(t, shot, camera) {
      cam = camera; sky.position.copy(cam.position);
      const fn = SH[shot.v]; if (!fn) throw new Error('myset: no shot ' + shot.v);  // a typo shows as a placeholder
      return Object.assign({ scene, sun, maxR: 7, fgScale: 1.5, exposure: 1.1, sat: 1.06, bloom: 0.15, lift: [0.012, 0.016, 0.04], gain: [1, 1, 1] }, fn(t, shot));
    },
  };
})();
```
Each frame must render in under ~3 s.

## 6. The people rig

`PP2` (`lintel/people2.js`) draws with the feet at the origin and y up negative. One unit is `PP2.U` = 1.86/560 m. Every drawer is a pure function of its state object. The full spec is in `PP2_API.md`.

| Drawer | Poses | Other state |
|---|---|---|
| `samson` | `stand walk carry point lean sleep wake strain burst grind lookup pray push` | `hair` 0..1, `blind`, `shackles`, `bonds` (rope / bowstring / loom), `brk`, `gold`, `look`, `phase`, `k`, `t` |
| `delilah` | `stand turn call sit beckon` | `k`, `look`, `couch` |
| `person` | `stand raise hold kneel cheer fall` | `v` 0–11 (0–5 Israelites, 6–11 Philistines), `item` (scroll / chains / staff), `k`, `dir` |
| `lord`; `angel`; `manoah`/`mother` | `stand laugh fall`; `stand speak`; `stand object awe worried` | `dir`, `k`; `glow`; `shake` |
| `boy`; `bride`; `barber`; `lion`; `soldierFall` | `lead`; `jar stand`; (razor stroke `k`); `leap thrown crouch`; (topple `k`, `dir`) | |

- **Build and measure:** `PP2.bill(name, base, over)` (sizes from `PP2.SIZES`); `PP2.samsonInfo(st)` returns `{ head, hands }`; `PP2.ANCHOR` has `lap`, `sleepOnLap`, `prayHands`.
- **Pose on a word:** switch at the beat and ease `k`. From `sorek.js` traps, with `d = t - beat`: `pose: d >= 0 ? 'burst' : 'strain', k: q(ease.out(clamp(d / 0.22)), 30)`.
- **Can't do:**
  - expressions (each pose has a fixed tiny mouth and brow; act with poses, light and bubbles, 07 §2);
  - walking, except Samson and the boy;
  - motion blur.
- **New character:** a new drawer inside `people2.js` (its helpers are private) plus a `SIZES` entry. Older drawers: `PP.soldier`, `PP.judean`, `PP.samson`.

## 8. Voice and word timing

1. **Before the take,** `make_vo.py` estimates the times (182 wpm).
2. **The take** (ElevenLabs, 04). Ep 1's: `ep01-samson/voice_lab/take1/` (`mike_take1.mp3` → `voice.wav` → `voice_edit.wav`; the commands weren't saved, **(inferred: ffmpeg)**).
3. **ASR word times:** `python3 ep01-samson/voice_lab/take1/align_take.py <episode.md> <voice.wav> <dir>/words.json` (sherpa-onnx, via `/home/claude/fourth-watch/engine/voice.py`). Check its `heard.txt` against the script.
4. **Per-token times:** `python3 <film>/tools/words_from_voice.py <episode.md> <dir>/words.json <dir>/flat.json` (it reports mismatched lines).
5. **The real `vo.js`:** `python3 <film>/tools/make_vo.py --words <dir>/flat.json` (asserts equal counts; rewrites `vo.js` and `out/captions.srt`).
6. **The soundtrack:** `VOICE=<wav> node song.js`.

**After a re-record or splice:**
1. Make `episode.md` match the audio word for word, then re-run steps 3–5 on the whole file. Unchanged words re-time themselves; a missing cue word throws at `require('./score.js')`.
2. **If VO lines were added, cut or reordered, every later `cue(line, …)` points at the wrong line.** Renumber them, run the `CUE_LOG` check (§3 step 7), then `node ../../tools/shotlist_check.js . --score score.js`.
3. Re-render every part after the first changed word, and rebuild the soundtrack.

## 9. Rendering

Run from the film folder with `CHROME_PATH` set. Times can be seconds or `@marker±s`.

| Mode | Output |
|---|---|
| `stills t …` | `out/stills/t_012.30.png` |
| `sheet a b n cols` / `board [t …]` (default: every shot start) | `out/sheet.png` / `out/board.png` |
| `clip a b [workers] [--hq] [--draft] [--gif]` | `out/clip_<a>-<b>[-draft].mp4`. Default: JPEG, crf 20. `--hq`: PNG, crf 15, slow. Sound only if `out/music.wav` exists |
| `video [workers]` / `mux [name] [--subs]` | `out/video.mp4` (PNG, crf 14, locked) / `out/<name>.mp4` (+ `out/music.wav`, length checked) |
| `check`, `verify`, `preview` | Loudness + contact sheet; sync at `sync` markers; live preview. Other modes are unused template tools |

**Flags:** `--draft` halves the frame, but the 3D pass stays at 1080×1920, so expect less than the header's "2–4×" **(inferred; no draft run was logged)**. `--res`, `--format`, `--style` are template features (keep 9:16). Environment: `CHROME_PATH`, `FFMPEG_PATH`, `FFPROBE_PATH`. Workers default to 2.

**Speeds (Ep 1 v57 logs):** `--hq` parts 0.17–0.21 fps (P1: 902 frames in 72 min; P4: 936 in 91 min); the title part 0.30 fps; a 2D-only tail 1.2 fps; stills 0.8–5 s each. A 145 s reel takes about 6 h.

**The Ep 1 flow:**
1. `out/parts57.txt` lists the parts (`NAME FROM TO`, 27–31 s, cut on shot boundaries).

## 10. Pitfalls, and before you change the engine

09 §4 first: the 2 h job cap (parts ≤ 30 s), no `pkill -f`, prefix cues, `maxW`, pure frames.

From the code:
1. **Beat names are a contract.** Scenes, cards and the song read beats by name. A missing name gives `NaN` in a card and a silent `??` fallback in a scene. The linter counts every `beats` value, acted or not.
2. **Scenes read the score at build time.** `dagon.js` builds its timeline from the first 'pillars' and 'fall' shots. `score_v58.js` has no 'pillars' shot, so dagon would fail to build **(inferred)**.
3. **An unknown `v` falls back silently** to the module's default shot; an unknown `scene` shows "scene not built yet".
4. **The song reads shot IDs** (`S('S02')`). Renaming a shot makes it throw.
5. **`FW.mat` caches materials:** recolouring one mesh recolours all that share it. Use `{ unique: true }`.
6. **Keep the light count constant,** and copy the camera position to the sky dome in `frame()` (`LW.sky` follows one frame late).
7. **Changing `END_T` or any timing** invalidates every later part. Ep 1's P5 was rendered under the old `END_T` and patched with Q2.
8. **Harmless log noise:** the `only.js` 404 and the `three.min.js` determinism warning. Real errors read `[w0] LOG error`.
9. **`render_part.sh` takes the newest `out/clip_*.mp4`,** so run one clip per folder at a time **(inferred)**. `video` and `mux` lock `out/.render.lock`.

**Before you change the engine:**
1. Back up the file first: `cp lintel/cards.js lintel/cards_v02a_pre_<change>.js`.
2. Keep it deterministic: no `Math.random`, `Date.now`, `performance.now` or `new Date` (`render.js` warns); use `FW.rng(seed)`, `hsh(i, k)`, `FW.noise2`/`fbm`; carry no state between frames.
3. Keep old field names working, and change one file at a time.
4. Test: `node -e "require('./score.js')"`, stills in the changed shots, a 2–3 s clip, then the log errors.
5. Update `scenes/_API.md`, `PP2_API.md` and this file.
6. Fix the source and re-render. Never patch the video.
