# Test plan

**Status: not run.** Running it needs Marcus's approval because it uses about eight agent runs.

Each run gets the same brief and the same ESV passage, in a fresh session. The brief: "Write the strongest Fourth Watch script you can from this passage." If the writer's topic gate rejects a passage, it still writes its best script, so every pair can be compared.

| # | Passage | Why it's a good test |
|---|---|---|
| 1 | Luke 7:11-17, the widow of Nain | Compassion, with very little text |
| 2 | Acts 9:10-19, Ananias | Fear and obedience, in a minor character |
| 3 | 2 Kings 6:8-17, the servant's eyes opened | Wonder |
| 4 | Numbers 20:1-13, why Moses couldn't enter the land | A hard question people already search for |

**Baseline:** the current `fourth-watch-writer`. No test uses a passage shown in `preliminary_walkthroughs.md` or in the annotated scripts.

**What counts as better:** Marcus prefers it blind, for reasons he can state, and real listeners can say what changed and who they'd send it to. Passing checks doesn't count.

**If it doesn't win:** keep the writer, and find out which part of the skill failed before changing anything.
