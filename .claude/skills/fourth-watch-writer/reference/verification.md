# Verification: labels, sources and the traps we have already fallen into

## Label every claim in the dossier
| Label | Meaning | How the script may say it |
|---|---|---|
| **TEXT** | The ESV says it explicitly | As fact, or quoted word for word |
| **HISTORY** | A historical or archaeological fact from a named, reputable source | As history ("Historians date…", "In that culture…"), never as Scripture; the source goes in the dossier |
| **INTERPRETATION** | A reading that mainstream commentators hold, but the text doesn't state | Attributed ("Many Christians read this as…", "One common explanation…"); if Christians differ, name the main views in one line, or put it in the caption |
| **SPECULATION** | Plausible but unsupported | **Not in the script** |

## Sources, in order
1. **The ESV text.** Fetch it from esv.org (or the biblehub ESV pages when esv.org is blocked) in this session. Never quote from memory. biblegateway is often blocked by the proxy.
2. **ESV footnotes** for word meanings and alternative readings.
3. **Mainstream study resources**, for what a reading *is*, not for what the text says: ESV Study Bible notes, Got Questions, The Gospel Coalition, Bible Project, standard commentaries.
4. **History and archaeology:** encyclopedias, university or museum pages, peer-reviewed summaries. Cite them in the dossier.

The order matters: a WebSearch first puts the URL in provenance, and then WebFetch can read it.

## The traps we have already fallen into (check every draft for these)
| Trap | Real case | The rule |
|---|---|---|
| A quoted verb that isn't the ESV's | "came upon him" for "rushed upon him"; "Esau I hated" in a Malachi line (Mal 1:3 is "I **have** hated") | Quoted words match the ESV exactly, in the book you name |
| An implied event stated as fact | "God answered" (Samson); "he forgave" (Gen 33 has no "forgave") | Show what the text records; let the viewer infer |
| A future announcement stated as done | "God judged Edom" from Obadiah, which says "shall" | Match the tense ("condemned", "warned") |
| A flat definition | "'Hated' means loved less" (Malachi also shows judgment) | "can mean", plus the counter-evidence named |
| One side of a debate taken silently | "God chose Jacob's line" (the Romans 9 debate) | Neutral wording, or name both views |
| The narrator stating a character's words as fact | "whose face was like seeing the face of God" | "whose face Jacob said was…" |
| A collective label applied to one person | Malachi's nation-level "hated" applied to Esau the man | Check who the text applies it to |
| An action overstated | "the liar got lied to" (Laban deceived by action, never stated a lie) | Use the text's own verb ("deceived") |
| "Last", "only", "never", "all" | "the last time…" | Only if the text makes it so |
| A historical fact presented as Scripture | Nineveh's size (Jonah) | Say it as history, with its source |
| A translation's word used as if it were the ESV's | "burning incense" (NIV) where the ESV has "made offerings" | Paraphrase freely, but don't say "the Bible says X" when the ESV says Y |

## The fact-check brief (for the Stage 6 agent)
Use the brief in `fw-script-review` (A. ESV fact-checker), plus these lines:
- "Label each line TEXT / HISTORY / INTERPRETATION and say whether the script presents it at the right level."
- "Rule on every cross-reference: does the later text name or quote the earlier one, or is it a reading? If it is a reading, does the line say so?"
