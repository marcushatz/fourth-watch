# Reviewer prompts (copy, fill the {{slots}}, launch as fresh agents)

These are the exact briefs used on Ep 1 on Oct 31, with what they taught us folded in. Each reviewer must be a **fresh agent that has never seen a draft**. Give it only what its prompt lists, so its read isn't anchored on ours.

| File | Reviewer | Tools | When |
|---|---|---|---|
| `A_esv_factcheck.md` | ESV fact-checker: lines, verse cards and pictures | Web (ESV sites) | Every script revision; every shot list |
| `B_first_time_viewer.md` | An 18–30 year old hearing it once | None | Every script revision |
| `C_cold_editor.md` | A short-form editor and script doctor | None | Every script revision |
| `D_director.md` | A storyboard director (one picture per sentence) | None | Every script revision |
| `E_shotplan_review.md` | A fresh director reviewing the shot plan file | Read three files only | Every shot list, before Marcus sees it |
| `F_variant_test.md` | Two fresh simulated (AI) viewers, one per variant, for a decision | None | When Marcus must choose between versions |
| `G_evidence_audit.md` | An auditor checking a rules file against its evidence | Read files | Whenever a rules file changes |

**How to launch:**
1. Put A–D in ONE message so they run in parallel, in the background.
2. Merge their findings with `fw-script-review` §3 (accuracy first; Marcus's rules win).
3. Save each reply word for word in `ep*/qa/<round>/` (one file per reviewer), then log the summary in `reviewers.md`. Quote only from the saved replies.

**Lessons from Oct 31:**
- **The fact-checker must get the pictures too.** It caught six picture errors the script checks never would.
- **Two fresh simulated viewers on two variants** turn an opinion ("is the warning too harsh?") into a comparison of where each version confuses or drags. They are AI role-play, not audience data: they can't measure retention or sharing (Round 17).
- **Reviewers suggest wording that breaks our rules.** For example, "the strength still came" implies God answered. Re-check every suggestion against the ESV before taking it.
- **An audit agent** found 13 overstated figures in our own rulebook. Audit every rules file after a big change.
