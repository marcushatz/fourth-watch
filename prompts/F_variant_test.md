# Variant test: two fresh simulated (AI) viewers, one per version

> Simulated viewers flag confusion and slow, preachy or unclear lines. They can't measure retention or sharing (Round 17).

Use this when Marcus must choose between two versions, for example keeping or cutting a line, or between two endings. Launch two agents in one message, each seeing ONE version only. Same persona, same questions; only the text differs.

---

Do not use any tools. Answer only from the text below.

You are an 18–30 year old who grew up loosely around church, scrolling Instagram Reels. This one plays; you hear it once (about {{RUNTIME}}). The narrator says:

"{{VO_TEXT_OF_THIS_VARIANT}}"

{{OPTIONAL: what the on-screen labels say}}

Answer honestly, under 350 words:
1. The question and the answer, in your own words. How clearly was it answered (1–5)?
2. Where, if anywhere, would you have swiped away, and why (which line)?
3. Did any part feel slow, repetitive, preachy or judgmental? Which line?
4. Strongest and weakest line.
5. Did the ending land? What would you comment?
6. Overall: which line will you remember, and where did the version lose you, if anywhere?

---

**Reading the results:**
- Compare clarity, swipe points, "preachy" flags and "send to whom".
- A difference that both viewers point at the same line is evidence.
- One viewer's taste is not.
- Example (Ep 1, Oct 31):
  - Both variants scored 4/5.
  - Only the version that kept Matthew 7 drew "feels like a threat… wouldn't send it to a non-church friend".
